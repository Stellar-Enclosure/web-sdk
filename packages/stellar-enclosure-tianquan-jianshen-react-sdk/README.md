# Stellar Enclosure Jianshen React SDK

React integration for the Jianshen Identity Provider. Public package: `@stellar-enclosure/stellar-enclosure-tianquan-jianshen-react-sdk`; initial version: `0.0.1`. React and React DOM are peer dependencies.

## Publication

From the `web-sdk` repository root:

```bash
npm ci
npm run release:jianshen -- --dry-run
npm run release:jianshen
```

Publishing requires npmjs authentication and access to the `@stellar-enclosure` organization. Tests run before publication; packing rebuilds JavaScript and TypeScript declarations. See the [repository release commands](https://github.com/Stellar-Enclosure/web-sdk#publish-to-npmjs) for versioning and verified tarball publication.
